# korora

**Modular**, **extensible** and **beautiful** wedding website using **[React](https://react.dev)**, **[Vite](https://vite.dev)**, **[Hono](https://hono.dev)**, **[Prisma](https://www.prisma.io)**, **[Tailwind CSS](https://tailwindcss.com)** and **[Embla Carousel](https://www.embla-carousel.com)** with **[daisyUI](https://daisyui.com)**, **[Motion](https://motion.dev)** and **[Better Auth](https://www.better-auth.com)**. Hosted on **[Vercel](https://vercel.com)** with a **[Prisma Postgres](https://www.prisma.io/postgres)** database. Fonts licenced via **[BeFonts](https://befonts.com)**.

**[Live Demo](https://korora.joshuasoong.studio)**

## Features:

- [x] Authentication
- [x] Maps
- [x] RSVP form
- [x] Image Gallery
- [x] Gift Registry
